Model Source

Configure where the serving runtime loads the model from.

Optional

Skip this step if your serving runtime already contains the model.

Model Path

Specify the path to the model directory inside the selected PVC.

Example: /models/llama3

If PVC = model-storage and path = models/llama3, KServe will generate:

pvc://model-storage/models/llama3
Generated Storage URI

pvc://{{ wizard.pvcName }}/{{ wizard.modelPath }}
